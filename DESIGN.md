# AMD Fan Control interface

Operate surface: one compact desktop window, curve and telemetry immediately
visible. User provided Material minimalism and system dark mode as constraints.
Implementation proceeds directly from that brief; no generated visual comp.

Use the original three-blade fan symbol in `assets/icon.svg`. Accent #a82326,
light surface #faf8f6, foreground #242224; dark surface #18191c, foreground
#f4f0ed. Native Segoe UI/system font keeps installation and network costs low.
8px spacing base, 12px controls/panels, 16px body, clear 24px section titles.

Native SVG line chart, solid control points with 44px hit areas, numeric
alternatives for keyboard editing. Error messages persist and explain recovery.
Unavailable telemetry is an em dash. Commands have pending/disabled feedback.
Draft points are clearly distinct from the saved/applied curve. No background
animation or timers beyond backend status updates and UI freshness detection.
